Cài trên Windows (chạy ngầm)

  1. Cài cloudflared, bằng winget hoặc file .msi ở trên:

    winget install --id Cloudflare.cloudflared

  2. Cài relay làm task nền. Mở PowerShell trong thư mục chứa 9r-relay.ps1. Script tự xin quyền Administrator, rồi hỏi Client ID và Client Secret:

    powershell -ExecutionPolicy Bypass -File .\9r-relay.ps1 -Install

    Script tạo task 9router Relay: chạy bằng SYSTEM từ lúc khởi động máy, không mở cửa sổ nào, tự chạy lại khi bị ngắt. Script, cloudflared và token được lưu ở C:\ProgramData\9r-relay, chỉ Administrators đọc được.

  3. Kiểm tra. Dòng Listener phải là OPEN, lệnh curl phải trả 200:

    powershell -ExecutionPolicy Bypass -File .\9r-relay.ps1 -Status
curl.exe http://127.0.0.1:20130/v1/models -H "Authorization: Bearer <API key>"

Service token và API key không có trên trang này. Lấy chúng trên máy nhà, trong C:\Users\lampt\.9r-relay\ (credentials.json và api-key.txt). Mỗi máy nên dùng một API key riêng, tạo trong dashboard 9router.

Cấu hình Codex trên máy client

File %USERPROFILE%\.codex\config.toml:

model = "cx/gpt-6.1-sol"
model_provider = "9router"
model_context_window = 500000

[model_providers.9router]
name = "9Router (relay)"
base_url = "http://127.0.0.1:20130/v1"
wire_api = "responses"
http_headers = { Authorization = "Bearer <API key>" }

SDK tương thích OpenAI

OPENAI_BASE_URL=http://127.0.0.1:20130/v1
OPENAI_API_KEY=<API key>
