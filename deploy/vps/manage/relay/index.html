9router Relay

Dùng 9router trên vps2 từ mạng bị chặn: một file .exe, mã hóa đầu-cuối, chạy như Windows service.

Thông số kết nối

Base URL cho client
http://127.0.0.1:20130/v1
Relay
wss://gw.lampt.works/v1/tunnel (HTTPS 443)
Lớp 1: Cloudflare Access
Service token, được cài tự động từ mã ghép đôi
Lớp 2: thiết bị
Khóa X25519 riêng của từng máy, tạo trên chính máy đó, không bao giờ rời máy. Thu hồi được từng máy.
Mã hóa
Noise IK (X25519, ChaCha20-Poly1305, SHA-256). Cloudflare và proxy công ty chỉ thấy dữ liệu đã mã hóa.
Lớp 3: 9router
API key của 9router, mỗi máy một key
Phạm vi
Chỉ /v1/*. Dashboard và API quản trị luôn trả 404.

Đường đi của request

  1. 1
    Codex / SDKgọi http://127.0.0.1:20130/v1 trên chính máy đó
  2. 2
    Service 9router Relaymỗi kết nối mở một WebSocket ra ngoài và bắt tay Noise, server được ghim khóa
  3. 3
    Cloudflare Accesschặn mọi kết nối không có service token
  4. 4
    relay-server trên vps2chỉ chấp nhận thiết bị đã ghép đôi, giải mã, chuyển vào Caddy (chỉ /v1)
  5. 5
    9routerkiểm tra API key, rồi định tuyến tới provider

Cài trên Windows

  1. Lấy mã ghép đôi. Admin tạo mã trong Cockpit (manage.lampt.works → 9router & Relay → Tạo mã ghép đôi). Mã dùng một lần, hết hạn sau 10 phút.

  2. Cài service. Mở PowerShell bằng Run as Administrator, chuyển vào thư mục chứa file .exe:

    .\9r-relay-windows-amd64.exe install 9r1.<mã ghép đôi>

    Lệnh này tạo khóa thiết bị, ghép đôi với server, chép chương trình vào C:\Program Files\9r-relay, rồi cài service 9router Relay: tự khởi động cùng Windows, không có cửa sổ, tự chạy lại khi lỗi. Cấu hình và khóa nằm ở C:\ProgramData\9r-relay, chỉ SYSTEM và Administrators đọc được.

    Nếu mạng công ty bắt buộc đi qua proxy, thêm --proxy http://proxy:8080.

  3. Kiểm tra. test phải in end-to-end path OK:

    & "C:\Program Files\9r-relay\9r-relay.exe" status
& "C:\Program Files\9r-relay\9r-relay.exe" test

Cấu hình Codex trên máy client

File %USERPROFILE%\.codex\config.toml:

model = "cx/gpt-6.1-sol"
model_provider = "9router"
model_context_window = 500000

[model_providers.9router]
name = "9Router (relay)"
base_url = "http://127.0.0.1:20130/v1"
wire_api = "responses"
http_headers = { Authorization = "Bearer <API key>" }

SDK tương thích OpenAI

OPENAI_BASE_URL=http://127.0.0.1:20130/v1
OPENAI_API_KEY=<API key>

API key của 9router không nằm trong mã ghép đôi. Tạo key riêng cho từng máy trong dashboard 9router (Endpoint → API keys).
