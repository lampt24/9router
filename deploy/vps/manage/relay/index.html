9router Relay

Kết nối tới 9router trên vps2 từ mạng bị chặn, qua Cloudflare (HTTPS 443).

Codex / SDK ──http──► 127.0.0.1:20130  (relay client: cloudflared access tcp)
   ══ WebSocket qua HTTPS :443 ══► Cloudflare Access  (bắt buộc service token)
   ──► tunnel 9router-vps2 ──► Caddy 127.0.0.1:20129  (chỉ /v1, luôn gắn X-Forwarded-For)
   ──► 9router 127.0.0.1:20128  (bắt buộc API key)

Cài đặt trên Windows

  1. Cài cloudflared: winget install --id Cloudflare.cloudflared, hoặc dùng file .msi ở trên.
  2. Tải 9r-relay.ps1 vào một thư mục, ví dụ %USERPROFILE%\9r-relay.
  3. Lần đầu chạy để nhập service token. Script sẽ hỏi Client ID và Client Secret, rồi lưu vào %USERPROFILE%\.9r-relay\credentials.json (chỉ user của bạn đọc được): 
    powershell -ExecutionPolicy Bypass -File .\9r-relay.ps1 -Setup
  4. Các lần sau chỉ cần chạy và giữ cửa sổ mở: 
    powershell -ExecutionPolicy Bypass -File .\9r-relay.ps1
  5. Kiểm tra (kết quả mong đợi là 200): 
    curl http://127.0.0.1:20130/v1/models -H "Authorization: Bearer <API key>"

Service token và API key không có trên trang này. Lấy chúng từ máy nhà: C:\Users\lampt\.9r-relay\credentials.json và api-key.txt. Tạo key riêng cho từng máy trong dashboard 9router (Endpoint → API keys).

Cấu hình Codex trên máy client

File %USERPROFILE%\.codex\config.toml:

model = "cx/gpt-6.1-sol"
model_provider = "9router"
model_context_window = 500000

[model_providers.9router]
name = "9Router (relay)"
base_url = "http://127.0.0.1:20130/v1"
wire_api = "responses"
http_headers = { Authorization = "Bearer <API key>" }

SDK tương thích OpenAI: OPENAI_BASE_URL=http://127.0.0.1:20130/v1, OPENAI_API_KEY=<API key>.
